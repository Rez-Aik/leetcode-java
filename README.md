# LeetCode Java Solutions

A structured collection of LeetCode solutions
implemented in Java.

The repository is designed to improve algorithmic
problem-solving skills and prepare for technical
interviews.

## Technologies

- Java 25
- Maven
- JUnit 5
- IntelliJ IDEA

## Repository Structure

- `src/main/java` — problem implementations
- `src/test/java` — unit tests
- `docs` — algorithmic patterns
- `docs` — computer science and Java theory
